# Human robot interaction project

0. Environment - Unity engine with Unity CLI enabled. (in HRI_room_drone folder)

1. User will provide a 3D model of a dormitory room compatable with Unity engine.
2. User, guided by the agent will populate the room with static object (i.e. bed, chair, sink, wardrobe)
3. User, will populate the room with active objects, objects bein collectable trash in the room. (i.e. soda can, tissues, full garbage bag, etc.)
4. User will find a 3D model of a mini drone and add it to the project scene.
5. DRONE BEHAVIOUR: 
	a. Fly to the user and tell them to wake up and clean the room
	b. User should press "E" to wake up, then the user can move with WASD and move camera with mouse
	c. Drone should then fly near the closes (TO THE DRONE) "trash" object and "light it" there should
		I. there should be a ray coming from drone, and the object should get a yellow outline
	d. After marking the object drone should state the name of the object and tell user to pick it up
	e. After user comes near the object, they should press "E" to "collect" it or clean it. (depends if the 	object is marked as "movable trash" or "surface dirt")
	f. After user collects it. Drone should congratulate the user, and encourage them to collect/clean next 	object.
	g. repeat from step c. until the room is clean.
	h. after the room has been cleaned, drone should congratulate the user, fly to a charging station asset and 	turn off.
6. After the cleaning is complete, the "game" should be finished and user should see a screen "cleaning complete"
7. Then the user will see a questionary with those options
	I.   Did you feel encourage to collect the trash, after the robot pointed it out?
	II.  Did you like the encouragement from the robot?
	III. Do you think that you would clean your real room more often with such robot?
	IV. ... come up with relative questions for the scope of Human Robot interaction.
8. Text and Voice for the robot, let's use local Qwen3-TTS model.
